# FeC-NEP-model-data
This is the data for the potential training of the paper : "Development of a MLIP under the NEP framework for radiation induced defects in ferrite and ferrous carbides" [1]. The potential is capable of reproducing key properties of ferrite and carbides as well as defective structures mixing FeC such as interstitials, interfaces, grain boundaries, surfaces.

## How to use it 

To use this potential multiple codes are available:
* GPUMD [2]
* LAMMPS with NEP-CPU interface [3]
* Calorine python package [4]
* LAMMPS with MATPL interface with kokkos acceleration [5]
